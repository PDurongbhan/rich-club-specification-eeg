# Data

`ERR Data/` holds the 80 per-participant connectivity files analysed in this study: 20 participants with Alzheimer's disease and 20 controls, eyes-open and eyes-closed, in four folders by recording state and age band. Each file has one row per permissible pair of the 23 bipolar derivations (207 rows). In each file, column 1 is a row number and column 2 the channel pair; columns 3 to 7 hold the linear error-reduction-ratio connectivity for the five mini-epochs, which is what this study uses, and columns 8 to 17 hold further outputs of the same model.

The files were computed by Yifan Zhao with the pipeline of Zhao et al. (2020) from the resting-state EEG cohort described in Durongbhan et al. (2019), and are shared here with his permission under the Creative Commons Attribution 4.0 International licence (CC BY 4.0). The MIT licence in LICENSE covers the code only. If you use these files, please cite both papers.

Durongbhan, P., et al. (2019). A dementia classification framework using frequency and time-frequency features based on EEG signals. IEEE Transactions on Neural Systems and Rehabilitation Engineering, 27, 826-835. https://doi.org/10.1109/TNSRE.2019.2909100

Zhao, Y., et al. (2020). Imaging of nonlinear and dynamic functional brain connectivity based on EEG recordings with the application on the diagnosis of Alzheimer's disease. IEEE Transactions on Medical Imaging, 39, 1571-1581. https://doi.org/10.1109/TMI.2019.2953584
